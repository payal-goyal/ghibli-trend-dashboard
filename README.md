# 🎥 Ghibli Trend Dashboard

This Power BI dashboard visualizes key insights from Studio Ghibli films, highlighting trends in movie production, ratings, and audience reception.

## 📊 Key Features

- 🎬 Film Timeline: Explore the release history of Studio Ghibli movies.
- ⭐ IMDb Ratings Analysis: Compare ratings across films.
- 🧑‍🤝‍🧑 Character & Director Analysis: See which directors and characters appear most frequently.
- 📈 Trends Over Time: Understand how the studio’s output and reception evolved.

## 📁 File
- `Ghibli Trend Dashboard.pbix`: The Power BI file containing all visuals and insights.

## 🧠 Insights
- Hayao Miyazaki directed the most Ghibli films.
- A consistent trend of highly rated movies across decades.
- Key themes like nature, fantasy, and coming-of-age are common.

## 🛠️ Tools Used
- Power BI Desktop
- Public Studio Ghibli dataset (can be replaced with your source)

## 📌 Note
To view or edit the dashboard, download the `.pbix` file and open it using **Power BI Desktop**.
